## 📚 核心功能速查

### 1. 创建记录

```javascript
// 发卡记录
const issue = CardRegistry.createIssueRecord({
    name: '张三',
    idNumber: '110101199001011234',
    department: '第一连',
    cardType: 'Ⅰ类卡',
    cardNumber: 'BZK20240001',
    issueDate: '2024-01-01'
});
CardRegistry.addRecord(issue);

// 收卡记录
const recycle = CardRegistry.createRecycleRecord({
    name: '李四',
    idNumber: '110101199002022345',
    department: '第二连',
    cardType: 'Ⅱ类卡',
    cardNumber: 'BZK20240002',
    reason: '退伍回收',
    recycleDate: '2024-10-01'
});
CardRegistry.addRecord(recycle);
```

### 2. 搜索和过滤

```javascript
// 搜索
CardRegistry.searchRecords('张三');

// 过滤
CardRegistry.filterByCardType('Ⅰ类卡');
CardRegistry.filterByYear('2024');

// 获取结果
const results = CardRegistry.getFilteredRecords();
console.log('找到', results.length, '条记录');

// 重置
CardRegistry.resetFilters();
```

### 3. 导入导出

```javascript
// 导出Excel
CardRegistry.exportToExcel();

// 下载模板
CardRegistry.downloadTemplate();

// 导入
const fileInput = document.getElementById('importFile');
fileInput.addEventListener('change', async (e) => {
    const file = e.target.files[0];
    const count = await CardRegistry.importFromExcel(file);
    alert('导入成功：' + count + ' 条');
});

// 备份
CardRegistry.backupCompleteData();
```

### 4. 渲染和显示

```javascript
// 渲染表格
CardRegistry.renderTable();

// 更新统计
CardRegistry.updateStats();

// 切换标签
CardRegistry.switchSubTab('issue');    // 发卡
CardRegistry.switchSubTab('recycle');  // 收卡
```

### 完整示例

```html
<input type="text" id="searchInput" placeholder="搜索...">

<script type="module">
    import CardRegistry from './脚本/发卡收卡登记/入口.js';
    
    CardRegistry.init();
    CardRegistry.renderTable();
    
    window.handleSearch = function() {
        const keyword = document.getElementById('searchInput').value;
        CardRegistry.searchRecords(keyword);
        CardRegistry.renderTable();
    };
    
    window.handleFilter = function() {
        const cardType = document.getElementById('cardTypeFilter').value;
        CardRegistry.filterByCardType(cardType);
        CardRegistry.renderTable();
    };
</script>
```

## ⚠️ 常见问题

### Q: 模块加载失败？
**A:** 确保使用`<script type="module">`，且文件路径正确。

### Q: Excel导入不工作？
**A:** 确保已加载XLSX.js库：
```html
<script src="资源/xlsx.full.min.js"></script>
```

### Q: 数据没有保存？
**A:** 检查localStorage是否可用：
```javascript
if (typeof localStorage === 'undefined') {
    console.error('localStorage不可用');
}
```

### Q: 如何清空所有数据？
**A:** 使用清空功能（带二次确认）：
```javascript
CardRegistry.clearAllData();
```
