# ⚠️ 存档说明(2026-09-10)

本目录是"发卡收卡登记"模块化重写的**未完成存档**,不是可用代码,主程序未加载本目录任何文件。

生产环境实际使用的是单文件版 `脚本/发卡收卡登记.js`(由 主程序.html 加载)。

## 为什么被存档

经代码审查发现本目录存在以下未完成的严重问题,直接接入会导致功能崩溃或用户数据丢失:

1. `入口.js` import 引用了不存在的文件名(界面渲染.js,实际是 页面渲染.js),模块链断裂
2. `事件处理.js` 从其他模块导入了大量不存在的函数,ES Module 静态校验直接报错
3. 渲染层内联调用的 `window.REG` 从未定义,所有按钮点击即报错
4. `saveRecords()`/`saveConfig()` 无参调用,导入/备份/清空操作不会落盘
5. 与旧版共用 `cardRegistry.*` localStorage 键,但记录数据结构不兼容(旧版嵌套/新版扁平),互相污染
6. 缺少旧版约一半的功能(行内编辑、状态切换、打印、家属导入、批量编辑等)

**目录内的 说明.md / 模块完成总结.md / 快速开始.md 声称"10/10 完成、生产就绪",与代码实际状态不符,请勿采信。**

## 如需重启模块化

需先解决上述全部问题,并:
- 使用带版本号的独立存储键,或编写旧数据结构迁移层
- 在隔离环境中与旧版并行验证后再切换
