# 点击助手(Click Assistant)

一个**单文件、免安装、跨平台**的自动点击 / 自动输入 / 表格数据提取工具。
纯 C 编写、**零第三方库**、约 1.3 万行代码,Windows 版静态编译单 exe,Linux 版仅依赖系统自带的 libX11 + libXtst。

## 下载(按系统 / 架构选择)

到 [**Releases**](../../releases) 页面选择对应版本(当前最新 **v1.7.0**):

| Release 产物 | 系统 | 架构 | 说明 |
|---|---|---|---|
| `click-assistant-windows-xp-x86.zip` | **Windows XP SP3** ~ Win11 | x86(32 位) | 零依赖单文件 exe,Win7/10/11 的 32/64 位通用 |
| `click-assistant-linux-x86_64.tar.gz` | Linux(桌面发行版) | x86_64 / AMD64 | **零依赖**(仅 X11 桌面自带的 libX11 + libXtst) |
| `click-assistant-linux-arm64.tar.gz` | Linux | **ARM64 / aarch64**(树莓派 4/5、ARM 小主机、国产 ARM 平台如银河麒麟 V10) | 原生编译,glibc 2.17 基线 |
| `click-assistant-linux-armhf.tar.gz` | Linux | ARM32 / armhf(树莓派 3 等 32 位系统) | 原生编译 |

> **Windows on ARM(Surface Pro X /骁龙本)**:直接使用 `windows-xp-x86` 版,
> Win11 ARM 的内置 x86 模拟即可运行,无需单独的 ARM64 版本。
>
> **Windows XP**:本项目自诞生起就保持 XP 兼容(32 位、静态链接、
> 仅使用 XP 自带系统库),`windows-xp-x86` 即 XP 版,无需单独下载。

Windows 版与 Linux 版共享同一套核心引擎(纯 C 编写,见 `src/core`),两端功能持续对齐。

## 功能一览

### 自动化执行(核心)

- **屏幕取点**:全屏半透明覆盖 + 十字线;**点哪里就取哪里的精确坐标**
- **点击类动作**:单击、双击、多击(次数/间隔可设)、右击、中击
- **文本输入**:支持中文(剪贴板粘贴方式,任何程序可用);**支持"输入前清空"**(自动 Ctrl+A → 删除 → 输入)
- **按键 / 组合键**:`ctrl+s`、`alt+tab`、`win+r`、`F5`、`enter` …
- **其它动作**:等待、滚轮(可正可负)、鼠标拖动(起点→终点平滑移动)
- **循环执行**:次数(0=无限)、循环间隔、开始倒计时、随机抖动
- **多步骤 TAB(Windows)**:多组任务分页管理、TAB 重命名、跨 TAB 跳转与子流程调用

### 数据与条件

- **Excel 数据源**:拖拽或点击导入 `.xlsx` / `.csv`,逐行迭代;
  输入文本支持 `{行}` / `{列名}` / `{列N}` 占位符取任意列(如 `账号:{账号} 密码:{密码}`);
  工作表与数据列可下拉选择;数据源按 TAB 独立绑定
- **找图**:框选模板(最大 256×256),全屏或「⊞ 框选区域」**局域识图**(区域外相似图不干扰);
  「动作」下拉:只定位/**单击/双击/三击图片中心**;容差选档或直接输 0-255;
  **找到可跳转、未找到也可跳转**(典型用法:"没找到下拉选项→先跳去点开下拉再回来找")
- **Excel判断**:读当前行**任意列**,按 `值=>步骤` 多分支跳转(如 `男=>2,女=>5,9527=>6`);
  **全不匹配可默认跳转**;分支只影响执行路径,Excel 行迭代不受影响
- **颜色判断**:屏幕取色点与目标色比对(容差可设),满足则跳转
- **等窗口**:等待标题包含指定文本的窗口出现再继续(比固定延时可靠,超时可设)
- **读文本(OCR)**:识别区域内的文字(内置轻量模板匹配,支持数字/字母/常用符号),
  可设关键词:命中则跳转(常用于"等待页面出现某提示后继续");中文与艺术字体暂不支持
- **子流程调用**:执行另一 TAB 的步骤后**自动返回**调用处下一步(公共流程如登录只写一份,最多 8 层嵌套)

### 数据提取(v1.7 重点)

侧栏「**数据提取**」打开独立窗口,**不写代码完成"筛选 + 按结构出表"**:

- **双拖放槽**:表A(数据来源)与表B(列结构模板)各自拖入文件即选;
  也保留点击选择(文件对话框);两个文件一起拖入时自动分配
- **多条件筛选**:选好「筛选列 + 值」点「+ 添加」,条件数量不限(列表滚动);
  多条件**同时满足(AND)**,值为**包含式匹配**(填"儿"同时命中"儿子/女儿");
  「预览筛选结果」先看命中行数与前 5 行再导出
- **按表B 结构输出**:以表B 的表头为模板,从(筛选后的)表A 提取同名列;
  表B 有而表A 没有的列输出为空列;输出 CSV(UTF-8 BOM,Excel 双击直开)
- **三种格式全支持**:`.xlsx` / **`.xls`(Excel 97-2003 老格式,自研 BIFF8 解析器)** / `.csv`,
  表A 与表B 格式可任意混搭
- 双端一致(Windows 与 Linux 同一交互)

### 执行控制与界面

- **全局热键**:**F6 开始 / F7 暂停·继续 / Ctrl+F12 停止**(任何界面下生效;
  可在「设置」中改为任意 修饰键+主键 组合,三键互斥防冲突,注册失败会提示)
- **悬浮窗**:开始/暂停/停止/继续小窗,实时显示 **Excel 进度(N/M 与百分比)**;
  位置记忆(下次启动原位出现),按钮文字实时跟随快捷键设置
- **执行时主窗隐身**:开始执行自动隐藏主窗口(任务栏图标同步消失),结束/停止后自动恢复,Ctrl+F12 仍可停止
- **设置中心**:侧栏「设置」——主题色 8 色板点选即换、三组快捷键自由配置、一键恢复默认
  (存 exe 旁 settings.ini;Linux 版同样具备)
- **多选批量操作**:列表行首勾选框多选,右键批量 删除/禁用/启用/改前·后延时/整段上移下移;
  禁用的步骤执行时整轮跳过,列表显示"(禁用)"
- **执行可视化**:执行时当前步骤自动滚动到可见并选中高亮;运行日志区记录每步执行
- **定时执行**:侧栏「定时」设置每天 HH:MM 自动运行当前任务(随任务文件持久化)
- **任务文件 = 标准 CSV**:保存的任务可用 Excel 直接打开编辑再导回;
  支持中文/英文动作名、启用列、找图模板列(内嵌 Base64)、跨 TAB 跳转引用

## 各系统使用方式

### 🪟 Windows 7 / 8 / 10 / 11(最简单)

1. 下载 **`click-assistant-windows-xp-x86.zip`**,解压得到 `ClickAssistant.exe`(单个文件,约 770KB);
2. 双击运行即可 —— **无需安装、无需管理员权限、无运行库依赖**(32 位静态编译,64 位系统原生兼容)。

建议:把 exe 放在一个固定文件夹(如 `D:\点击助手\`),因为同目录会保存:

- `last_task.csv` —— 上次任务(自动保存 / 启动恢复)
- `settings.ini` —— 主题色 / 快捷键 / 悬浮窗位置等设置

全局热键:**F6 开始 / F7 暂停·继续 / Ctrl+F12 停止**(任何界面下有效)。

### 🪟 Windows XP / Vista

- 同上,下载 `windows-xp-x86` 版直接双击 —— 本项目自诞生起保持 XP SP3 兼容
  (32 位、静态链接、仅使用 XP 自带系统库),**XP 不需要单独的版本**。

### 🐧 Linux(x86_64 / ARM64 / 树莓派 / 银河麒麟)

1. 下载对应架构的压缩包(看不清架构就终端执行 `uname -m`):
   - `x86_64` → 普通 PC / Intel / AMD
   - `aarch64` → 树莓派 4/5(64 位系统)、ARM 小主机、银河麒麟 V10 等
   - `armhf` → 树莓派 3 等 32 位系统
2. 解压并赋可执行权限,即可运行:

```sh
tar xzf click-assistant-linux-arm64.tar.gz   # 换成你的架构
chmod +x click-assistant
./click-assistant
```

> Linux 版**零依赖**:界面为纯 X11 实现(libX11 + libXtst,任何 X11 桌面自带),
> 解压即用,无需安装任何软件包。

> **Wayland 用户**:输入模拟依赖 X11(XTest)。请在登录界面选"Ubuntu on X11"之类会话运行。

> **双端功能对齐说明**:Linux 版已具备 设置中心(主题色/组合键热键)、悬浮窗(进度百分比)、
> 暂停热键(F7)、全部动作类型(含找图/Excel判断)、Excel 数据源导入、批量操作、
> **数据提取(拖拽+筛选)**。仍仅在 Windows 版提供的:多步骤 TAB、跨 TAB 跳转/子流程调用、
> 定时执行、等窗口/颜色判断/读文本(OCR)动作的界面入口。

### 🍎 macOS

暂无原生版本。Mac 用户可在虚拟机 / Parallels 中运行 Windows 版。

## 使用说明

### 界面操作

1. **添加步骤**:点【添加】→ 选择步骤类型(卡片)→ 填写参数,点【≡ 屏幕取点】在屏幕上点一下即取该处精确坐标 → 确定
2. **修改步骤**:双击列表行,或选中后点【编辑】
3. **调整顺序**:选中步骤后【↑ 上移】【↓ 下移】,或右键菜单;勾选多行可**整段移动/批量操作**
4. **开始 / 停止**:【▶ 开始执行】或按 `F6`;**任何时刻按 `Ctrl+F12` 立即停止**;`F7` 暂停/继续
5. **执行前设置**:
   - 循环次数:`0` 表示无限循环
   - 循环间隔:每轮之间等待的毫秒数
   - 开始倒计时:点击开始后预留的反应时间(建议 ≥3000ms,把鼠标移到目标窗口)
   - 随机抖动:每个延时附加 0~N 毫秒随机量(更拟人)

### 数据提取怎么用(三步)

1. 侧栏「数据提取」→ 把**表A**(数据来源,如 `examples/测试数据100人.xlsx`)拖入上半窗口
2. 把**表B**(列结构模板,只需表头,如 `examples/测试表B.csv`)拖入下半窗口
3. *(可选)* 条件行选「列 + 值」→【+ 添加】(可加任意多条)→【预览筛选结果】看命中数
   →【开始提取】→ 保存 CSV

例:表A 有 姓名/性别/血型/年龄/出生日期 五列,表B 表头只有 姓名/性别/血型——
提取结果即 3 列 × (筛选命中的行);不加任何条件则输出全部行。

### 各动作说明

| 动作 | 需要填写的字段 | 说明 |
|---|---|---|
| 单击 / 双击 / 右击 / 中击 | X、Y | 点哪里就点哪里,坐标精确 |
| 多击 | X、Y、次数、间隔 | 连续 N 次单击 |
| 文本输入 | 文本内容(支持中文) | 剪贴板方式输入;勾选"输入前清空"会先 Ctrl+A 删除原内容 |
| 按键 | 文本列填组合键 | 如 `ctrl+s`、`alt+F4`、`win+r`、`enter`、`ctrl+shift+t` |
| 等待 | 前延时 | 停留指定毫秒数 |
| 滚轮 | 次数列填格数 | 正=向上,负=向下 |
| 拖动 | 起点坐标 + 终点 | 从起点平滑拖到终点 |
| 找图 | 框选模板(+可选搜索区) | 找到后可只定位/单击/双击/三击;容差 0-255;找到/未找到均可跳转 |
| Excel判断 | 列号 + 条件串 | `男=>2,女=>5`;全不匹配可默认跳转;行迭代不受影响 |
| 所有动作 | 前延时 / 后延时 | 执行前/后各等待多久 |

### Excel 导入格式(任务步骤)

第一行是**表头**(可省略,列顺序可打乱,按表头名识别):

| 动作 | X | Y | 次数 | 间隔毫秒 | 文本或按键 | 前延时毫秒 | 后延时毫秒 | 输入前清空 | 启用 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
| 单击 | 100 | 200 | | | | 0 | 200 | | 是 | |
| 输入 | | | | | 你好,世界 | 0 | 300 | 是 | 是 | 先清空 |
| 按键 | | | | | | | ctrl+s | 0 | 300 | | 是 | |
| 等待 | | | | | | | | 1500 | 0 | | 是 | |
| 滚动 | | | | | -3 | | | 0 | 200 | | 是 | |
| 拖动 | 100 | 100 | | | | | 500,400 | 0 | 200 | | 是 | 终点写在文本列 |

- **动作** 可写中文或英文(单击/双击/多击/右击/中击/输入/按键/等待/滚动/拖动/找图/Excel判断…)
- **拖动** 的终点以 `x2,y2` 写在"文本或按键"列;**滚动** 的格数写在"次数"列
- **是/否** 也可写 1/0、true/false;**启用=否** 的步骤执行时整轮跳过
- 保存的任务文件(`.csv`)就是这个格式,可直接用 Excel 编辑后再打开

> `.csv` 编码支持:UTF-8(推荐)、ANSI/GBK、UTF-16。
> **`.xls`(Excel 97-2003)老格式**:「数据提取」功能直接支持(表A/表B 均可);
> 任务步骤导入等其他入口仍请先另存为 `.xlsx` 或 `.csv`。

## 常见问题

**Q:为什么点击没反应 / 点错位置?**
执行期间不要移动鼠标;先在目标窗口上点一次让它获得焦点(可加一个"单击"步骤);多显示器下坐标基于虚拟屏幕,取点功能取到的就是实际坐标。

**Q:输入中文没反应?**
中文通过剪贴板输入(Ctrl+V),目标程序必须支持粘贴。部分游戏屏蔽粘贴,此时改用"按键"动作输入英文。

**Q:XP 上能跑吗?**
能。程序按 32 位 + 子系统 5.01(Windows XP)编译,不依赖任何运行库,DLL 仅使用 XP 自带的系统库(kernel32/user32/gdi32/comctl32/comdlg32/msvcrt)。

**Q:怎么停止?**
任何界面按 **Ctrl+F12**(全局热键)。当前动作完成后立即停止。执行期间主窗口自动隐藏,同样可用热键停止。

**Q:.xls 的 Excel 能直接用吗?**
「数据提取」窗口可以(拖入或点击选择均支持);其他 Excel 导入入口请先另存为 `.xlsx`。程序读取 `.xls` 使用自研解析器(只读第一个工作表;Excel 95 及更老版本会明确提示不支持)。

## 构建与测试(开发者)

**Windows**(需要 [MSYS2](https://www.msys2.org/) 的 MinGW-w64 i686 工具链:
`pacman -S mingw-w64-i686-gcc`,默认装在 `C:\msys64`):

```bat
build\windows_build.bat
```

关键参数:`-municode -mwindows -static -Wl,--subsystem,windows:5.01`

**Linux**(自动识别架构,依赖 GCC + X11 开发库):

```sh
sudo apt install gcc pkg-config libx11-dev libxtst-dev   # Debian/Ubuntu/树莓派
sh build/linux_build.sh
./dist/click-assistant
```

**运行单元测试**(与 CI `verify-linux` job 一致,仅链 core 层,不链平台/GUI;
Windows 下请在 MSYS2 shell 运行,`_WIN32` 下 `test_sheet.c` 等引用
`win_gbk_to_utf8`,可临时补一个返回 NULL 的桩):

```sh
gcc -std=gnu99 -O1 -Isrc/core tests/test_filter.c \
    src/core/u8.c src/core/inflate.c src/core/zip.c src/core/sheet.c \
    src/core/engine.c src/core/ac_keys.c src/core/import.c \
    src/core/findimg.c src/core/xls.c \
    -o /tmp/tf && /tmp/tf
```

> 换任意 `tests/test_*.c` 同理;`test_theme.c` 无独立 main,由 GUI 构建联编,单测时跳过。
> CI(`.github/workflows/release.yml`)每次发布跑 5 个构建目标(Windows XP 32 位静态 /
> Linux x86_64 / ARM64 / ARMhf)+ `verify-linux`(全部单测 + **ASan 内存消毒轮** + Xvfb GUI 冒烟)。
